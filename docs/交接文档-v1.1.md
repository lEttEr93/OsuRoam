# osu! Roam v1.1.1 交接文档

## 当前状态

- 版本：1.1.1
- 目标框架：net8.0-windows / win-x64
- 发布程序：`bin/v1.1.1/OsuRoam.exe`
- 源码入口：`MainWindow.xaml`、`MainWindow.xaml.cs`
- 推荐引擎：`Services/RecommendationEngine.cs`
- API 客户端：`Services/OsuApiClient.cs`
- 配置模型：`Models/AppSettings.cs`

## 关键行为

1. 星级范围按模式和 mania 轨道数分别保存。
2. 启动漫游不会自动覆盖星级；按钮计算只执行一次。
3. 搜索候选范围为最多 8 页、400 个 beatmapset。
4. `OsuBeatmapset.Tags` 接收 osu! API 的空格分隔 tag 字符串。
5. `TagPool`、`IncludedTags`、`ExcludedTags` 保存于 `settings.json`。
6. IncludedTags 是软偏好加分；ExcludedTags 是绝对过滤。
7. 推荐历史持久化并用于减少重复推荐。

## 本地配置

配置文件：`%LOCALAPPDATA%\\OsuRoam\\settings.json`

OAuth Secret 经过 Windows 用户凭据保护，不要复制配置文件到其他用户环境。

## 构建发布

```powershell
$env:PATH="C:\\Users\\<user>\\.dotnet;" + $env:PATH
dotnet build OsuRoam.csproj -c Release
dotnet publish OsuRoam.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o bin\\v1.1.1
```

## 后续开发注意

- 修改 `RecommendationEngine` 后应运行 `dotnet build`，再更新便携包。
- 发布前确认没有运行中的 `bin\\v1.1\\OsuRoam.exe`，否则单文件发布会因文件占用失败。
- 不要把 `bin`、`obj` 或个人配置混入源码快照。
- API tag 是作者自由填写文本，不应当被当作严格的音乐类型或技术类型字段。
