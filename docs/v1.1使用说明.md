# osu! Roam v1.1.1 使用说明

## 版本定位

v1.1.1 是当前稳定便携版本，包含双滑块星级筛选、手动星级计算、推荐池去重、tag 池和正反向 tag 筛选。

## 推荐流程

开始漫游时读取当前星级范围，调用 osu! API 搜索候选谱面，再由本地推荐引擎排序。搜索最多读取 8 页、约 400 个候选谱面。推荐池会记录历史 beatmapset，优先选择未推荐过的谱面。

正向 tag 只作为偏好加分，反向 tag 直接过滤。星级、BPM、时长和谱师匹配仍是主要排序依据。

## Tag 操作

在“推荐范围”中的 Tags 区域搜索并多选 tag，然后点击“加入推荐标签”或“排除这些标签”。已选区域的标签块可直接点击取消。API 新返回的 tag 会自动加入永久 tag 池。

## 发布文件

可运行程序：`bin/v1.1.1/OsuRoam.exe`

便携包：`bin/osu-roam-v1.1.1-portable.zip`

源码包：`bin/osu-roam-v1.1-source.zip`
