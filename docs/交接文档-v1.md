# osu! Roam v1 交接文档

## 版本基线

- 版本：`1.0.0`
- 目标客户端：osu!lazer
- 基线可执行文件：`bin/MoreProfileSamples/publish/OsuRoam.exe`
- 便携包：`bin/OsuRoamPortable.zip`
- 发布包：`bin/osu-roam-v1.0.0-portable.zip`

## 架构概览

- `MainWindow.xaml` / `MainWindow.xaml.cs`：浮窗界面、配置绑定、漫游流程和状态显示。
- `Services/OsuApiClient.cs`：osu! OAuth 和 Web API 请求。
- `Services/RecommendationEngine.cs`：候选谱面过滤、排序和推荐池补充。
- `Services/BeatmapDownloadService.cs`：镜像下载、缓存和 osu!lazer 导入。
- `Services/TosuClient.cs`：tosu WebSocket 连接和状态事件。
- `Services/TosuProcessManager.cs`：检测、启动和关闭 tosu。
- `Models/AppSettings.cs`：用户配置和各模式/mania key 难度范围。
- `Services/SettingsStore.cs`：配置持久化和 Secret 保护。

## 运行流程

1. 启动时读取配置并初始化浮窗。
2. 点击开始后调用 osu! API 构建玩家资料和候选谱面。
3. 推荐引擎按模式、mania key、星级、年份、长度和近期游玩规则排序。
4. 当前谱面开始游玩时预下载下一首。
5. 收到 tosu 的成功结算事件后导入下一首；失败、暂停或退出不会触发导入。

## 发布流程

当前机器没有 .NET SDK，因此 v1 使用已验证的框架依赖发布文件，并在便携包中携带 .NET 8 Desktop Runtime。重新制作便携包时：

1. 复制 `bin/MoreProfileSamples/publish` 的全部文件。
2. 放入 `tosu.exe` 和不含个人密钥的 `tosu.env`。
3. 放入包内 `dotnet/dotnet.exe`、`host/fxr/8.0.28`、`shared/Microsoft.NETCore.App/8.0.28` 和 `shared/Microsoft.WindowsDesktop.App/8.0.28`。
4. 保留 `启动 osu-roam.cmd`、`使用说明.txt`、`OsuRoam.ico` 和快捷方式。
5. 运行 `Compress-Archive` 生成带版本号 ZIP。

## 安全注意

- 不要把 OAuth Client Secret、用户配置目录或日志中的个人信息提交到仓库或分享给他人。
- 发布前检查 ZIP 中不存在 `settings.json`、凭据文件或包含 Secret 的文本。
- `tosu.exe` 来自用户已验证的版本，升级时需单独验证 WebSocket 兼容性。

## 后续开发建议

- 安装 .NET 8 SDK 后改为真正 self-contained 发布，减少包体积。
- 增加自动化测试覆盖推荐过滤、下载重试和 tosu 状态转换。
- 继续改善全屏下窗口层级和高 DPI 显示。
